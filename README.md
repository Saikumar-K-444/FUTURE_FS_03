#  Smart Health Care
Smart Health Care is a modern AI-powered healthcare web application designed to provide users with quick and easy access to health-related information in Telugu.
##  Features
- 🔍 Search diseases by name or symptoms
- 🤖 AI Health Report Popup
- 🎤 Voice Search (Telugu)
- 🔊 Text-to-Speech Support
- 💊 Medicine Information
- 📷 Medicine Scan (Demo)
- 🏥 Disease Categories
- 👨‍⚕️ Doctors Information
- 📅 Appointment Booking
- ⚖️ BMI Calculator
- ❤️ Daily Health Tips
- 🚑 Emergency Contact (108)
- 📱 Fully Responsive Design (Mobile & Desktop)
- 🌐 Telugu Language Support
## 🛠️ Technologies Used
- React.js
- HTML5
- CSS3
- JavaScript (ES6)
- Node.js
- Express.js
- MySQL
- Axios
- Web Speech API
